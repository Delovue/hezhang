## 角色丁本机验收

从干净版本安装锁定依赖，在根目录执行：

```powershell
backend/.venv/Scripts/python.exe scripts/acceptance.py --directory .e2e/acceptance-new
```

Linux/macOS 改用 backend/.venv/bin/python。结果中的 automated_status 表示自动化运行结果，acceptance_owner 为 role_d，acceptance_scope 为 local_preclass；课堂演示单独记为 classroom_demo=pending。environment.dirty=true 不可当作干净提交验证。本轮新目录安装、整系统回归、截图检查、联合启动、材料与发布检查见 [发布记录](RELEASE_V1.md) 和 [本机证据](verification/preclass-v1.json)。

旧模块报告保留开发期测试边界；其中未集成页面、结算或导出等均已在主分支完成。旧 JSON 的人工验收待办由新规则取代，不重写历史证据。
