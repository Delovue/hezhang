## 发现与修正

1. 首次在受限执行环境构建和运行 Vitest 时，esbuild 子进程启动被 EPERM 拒绝；改在允许启动子进程的环境验证后通过。首次受限后端测试出现 setup 错误后中止，未计入通过结果；正常环境重新执行得到上述 332 项通过。
2. 浏览器安装辅助脚本最初引用 Playwright 未导出的 `playwright/cli` 路径，出现 `ERR_PACKAGE_PATH_NOT_EXPORTED`；改为从包目录定位 CLI 后，重新执行安装命令通过。
3. 首次打包把整个 Element Plus 根入口指定成独立手工分块，产生约 920 KB 的 JS 块；移除该手工入口、按需注册所用组件后，最终主 JS 约 231 KB（gzip 约 88 KB），构建不再报告该大块警告。
